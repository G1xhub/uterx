Configuration

This chapter describes how to configure uterx to customize its behavior.

Configuration File

uterx uses a TOML configuration file located at:

  • Linux/macOS: ~/.uterx/config.toml
  • Windows: %USERPROFILE%\.uterx\config.toml

The configuration file is automatically created on first launch with default values and comments.

Default Configuration

# uterx Configuration File
# This file is automatically generated on first launch.

[terminal]
# Terminal settings
font = "JetBrains Mono Nerd Font"
font_size = 14
line_height = 1.2
letter_spacing = 0.0

[terminal.colors]
# Color scheme (Catppuccin Mocha by default)
# You can use named themes or custom colors
theme = "catppuccin-mocha"

# Custom foreground/background colors (overrides theme)
# foreground = "#cdd6f4"
# background = "#1e1e2e"

[terminal.scrollback]
# Scrollback buffer settings
max_lines = 10000
scroll_speed = 3

[terminal.cursor]
# Cursor style: block, bar, underline
style = "block"
# Blink interval in milliseconds (0 to disable)
blink_interval = 500

[ui]
# User interface settings

[ui.theme]
# UI theme (catppuccin-mocha, catppuccin-latte, etc.)
name = "catppuccin-mocha"

[ui.tab_bar]
# Tab bar settings
show = true
height = 1
show_index = true
show_broadcast_indicator = true

[ui.status_bar]
# Status bar settings
show = true
height = 1
show_session_badge = true
show_pane_count = true
show_broadcast_tag = true
show_keybinding_hints = true

[ui.file_browser]
# File browser settings
show_icons = true
show_hidden = false
max_search_results = 200

[ui.editor]
# Built-in editor settings
theme = "base16-ocean.dark"
tab_width = 4
line_numbers = true
auto_save = false

[ui.command_palette]
# Command palette settings
max_results = 10
fuzzy_match = true

[mux]
# Multiplexer settings

[mux.session]
# Session settings
auto_save = true
auto_restore = true
save_path = "~/.uterx/sessions"

[mux.pane]
# Pane settings
default_shell = ""
split_min_size = 10
border_width = 1

[mux.layout]
# Layout settings
default_split_ratio = 0.5

[plugins]
# Plugin settings
enabled = true
auto_update = false
registry_url = "https://plugins.uterx.dev"
plugins_dir = "~/.uterx/plugins"

[plugins.permissions]
# Permission settings
prompt_on_first_use = true
remember_decisions = true

[renderer]
# Renderer settings
backend = "auto"  # auto, opengl, vulkan, dx12
vsync = true
max_fps = 60

[renderer.glyph_atlas]
# Glyph atlas settings
width = 2048
height = 2048

[renderer.smooth_scrolling]
# Smooth scrolling settings
enabled = true
factor = 0.3

[keybindings]
# Custom keybindings
# Format: "key" = "action"
# Keys: Ctrl+Letter, Alt+Letter, F1-F12, etc.

# Example keybindings:
# "Ctrl+Q" = "quit"
# "Ctrl+T" = "new_tab"
# "Ctrl+W" = "close_pane"
# "Alt+H" = "split_horizontal"
# "Alt+V" = "split_vertical"

Available Themes

  • catppuccin-mocha - Dark theme (default)
  • catppuccin-latte - Light theme

[keybindings]

Custom keybindings.

Keybindings are specified as "key" = "action" pairs.

Key Format

  • Ctrl+Letter - Ctrl key combination (e.g., Ctrl+Q)
  • Alt+Letter - Alt key combination (e.g., Alt+H)
  • F1-F12 - Function keys
  • Shift+Key - Shift key combination

Actions

ActionDescription
quitQuit uterx
new_tabCreate new tab
close_tabClose current tab
close_paneClose current pane
split_horizontalSplit pane horizontally
split_verticalSplit pane vertically
focus_nextFocus next pane
focus_prevFocus previous pane
toggle_broadcastToggle broadcast mode
toggle_floatToggle floating pane
open_command_paletteOpen command palette
toggle_helpToggle help overlay
toggle_file_browserToggle file browser
open_uterxaiOpen UterxAI pane

Example Keybindings

[keybindings]
"Ctrl+Q" = "quit"
"Ctrl+T" = "new_tab"
"Ctrl+W" = "close_pane"
"Alt+H" = "split_horizontal"
"Alt+V" = "split_vertical"
"Alt+Left" = "focus_prev"
"Alt+Right" = "focus_next"
"Alt+B" = "toggle_broadcast"
"Alt+F" = "toggle_float"
"Ctrl+Tab" = "next_tab"
"Ctrl+Shift+Tab" = "prev_tab"
"Ctrl+P" = "open_command_palette"
"F1" = "toggle_help"
"Ctrl+E" = "toggle_file_browser"
"Ctrl+Shift+A" = "open_uterxai"

Environment Variables

uterx can also be configured via environment variables:

VariableDescriptionDefault
UTERX_CONFIGPath to config file~/.uterx/config.toml
UTERX_PLUGINS_DIRPlugin directory~/.uterx/plugins
UTERX_SESSIONS_DIRSessions directory~/.uterx/sessions
UTERX_LOG_LEVELLog levelinfo
UTERX_NO_RESTOREDon’t restore sessionfalse

Reloading Configuration

After modifying the configuration file, restart uterx for changes to take effect.
